Features

Built for developers

Every feature is designed to be useful, not just impressive. No bloat, no complexity.

Password Protection

Lock your database with a password. Uses Argon2 hashing, the industry standard for password security.

AES-256 Encryption

Data at rest is encrypted with military-grade AES-256-GCM. Your files are protected even outside the database.

Full SQL Support

SELECT, INSERT, UPDATE, DELETE, transactions. All the SQL you need without the complexity you don't.

Backup and Restore

One command to backup, one command to restore. Compressed with gzip, encrypted with your password.

CSV Import/Export

Move data in and out with standard CSV format. Perfect for migrations and data analysis.

Migration System

Version-controlled schema changes. Create, run, rollback. Track what changed and when.

Installation

Get started in seconds

Download the binary, make it executable, and you're ready. No dependencies, no configuration files.

Download Binary

curl -L https://github.com/farhanturu/tywindb/releases/download/v0.97/tywindb -o tywindb
chmod +x tywindb

Build from Source

git clone https://github.com/farhanturu/tywindb.git
cd tywindb && cargo build --release 
# Check installation
./tywindb --version
tywindb 0.97.0

# Show all commands
./tywindb --help
# Start interactive REPL
./tywindb repl

# Or use a specific database file
./tywindb repl --db mydata.tdb
Examples

See it in action

Real examples of what you can do with Tywindb. Copy these and try them yourself. 

# Create a users table
tywindb> CREATE TABLE users (id INTEGER, name TEXT, email TEXT, active BOOLEAN);
Table created

# Create an orders table
tywindb> CREATE TABLE orders (id INTEGER, user_id INTEGER, amount FLOAT, created_at TEXT);
Table created
# Insert single row
tywindb> INSERT INTO users VALUES (1, 'Alice', 'alice@example.com', true);
Query OK, 1 rows affected

# Insert multiple rows
tywindb> INSERT INTO users VALUES (2, 'Bob', 'bob@example.com', true);
Query OK, 1 rows affected

tywindb> INSERT INTO users VALUES (3, 'Charlie', 'charlie@example.com', false);
Query OK, 1 rows affected

# Insert order
tywindb> INSERT INTO orders VALUES (1, 1, 99.99, '2024-01-15');
Query OK, 1 rows affected
# Select all users
tywindb> SELECT * FROM users;
────────────────────────────────────────────────
                col_2 │ col_0 │     col_1 │ col_3
────────────────────────────────────────────────
    'alice@example.com' │     1 │   'Alice' │  true
      'bob@example.com' │     2 │     'Bob' │  true
  'charlie@example.com' │     3 │ 'Charlie' │ false
────────────────────────────────────────────────
3 rows

# Filter with WHERE
tywindb> SELECT * FROM users WHERE active = true;
────────────────────────────────────────────────
          col_2 │ col_0 │   col_1 │ col_3
────────────────────────────────────────────────
'alice@example.com' │     1 │ 'Alice' │  true
  'bob@example.com' │     2 │   'Bob' │  true
────────────────────────────────────────────────
2 rows
# Start transaction
tywindb> BEGIN;
Transaction started

# Make changes
tywindb> UPDATE users SET active = false WHERE id = 3;
Query OK, 1 rows affected

# Commit changes
tywindb> COMMIT;
Committed

# Or rollback if something went wrong
tywindb> BEGIN;
Transaction started

tywindb> DELETE FROM users WHERE id = 1;
Query OK, 1 rows affected

tywindb> ROLLBACK;
Rolled back
