Features

Everything You Need

Tywindb combines the best features from SQLite, PostgreSQL, and MongoDB into a single, easy-to-use package.

Password Protection

Secure your database with Argon2 password hashing. The strongest password hashing algorithm available.

AES-256 Encryption

Military-grade encryption for data at rest. Your data is protected even if the file is compromised.

Full SQL Support

Complete SQL syntax including SELECT, INSERT, UPDATE, DELETE, and transactions with BEGIN/COMMIT/ROLLBACK.

Backup & Restore

Compressed backups with easy restore. Keep your data safe with automated backup support.

CSV Import/Export

Import and export data as CSV files. Perfect for data migration and analysis workflows.

Migration System

Version-controlled schema changes. Create, run, and rollback migrations with ease.

Beautiful CLI

Colored output with formatted tables. A joy to use in your terminal every day.

Persistent Storage

Data survives restarts. Your database state is always preserved automatically.

Zero Configuration

No server, no setup, just run. The simplest way to add a database to your project.

Quick Start

Up and Running in Seconds

Get started with Tywindb in just a few commands. 

# Install Tywindb
curl -L https://github.com/farhanturu/tywindb/releases/download/v0.97/tywindb -o tywindb
chmod +x tywindb

# Start interactive REPL
./tywindb repl

# Or run a SQL file
./tywindb exec --db mydb.tdb script.sql
